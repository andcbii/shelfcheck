# Roadmap

## Version 3.0.0 wish list

### Grace periods

- Keep the current grace period as the global default.
- Allow each show to override the default grace period.

### Episode actions and review status

- Clicking an episode should open a menu with options to:
  - View the episode on Trakt.
  - View the episode on TMDB.
  - Mark the show as reviewed.
- Allow the reviewed status to be toggled off if it was selected accidentally.
- Change the episode's color to indicate that it has been reviewed.

### Series options

- Allow an individual show to use TVDB DVD order instead of the default episode order.
